# Evee landing page

Simple responsive React + Vite landing page using the four supplied Evee images.

Run `npm install`, then `npm run dev`. Create the production build with `npm run build`.

Includes mobile navigation, model posters, battery comparison tabs and full-size poster links. Product facts follow the supplied posters; those posters and comparison charts contain differing prices/specifications. The website link points to the domain printed in the supplied S1 Air image. No enquiry form or booking service is connected.
