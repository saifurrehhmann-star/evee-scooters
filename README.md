# Evee landing page

Responsive React + Vite page matching the supplied reference: hero, S1 Air and SQUBE model cards, lithium and graphene comparison charts, and footer. Assets are stored locally. Charts can be scrolled horizontally on mobile and opened full size.

Run `npm install` then `npm run dev`. Build with `npm run build`.

Product details follow supplied posters, which may differ from comparison charts. No booking or enquiry service is connected. Production build verified; browser visual QA unavailable in this session.
